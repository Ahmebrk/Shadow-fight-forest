# SHADOW CLASH 3D: BLOOD DYNASTY

## Run
- Open `shadow-clash-forest-3d.html` in a browser with internet access, because Three.js and the Oswald font are loaded externally.
- For a hosted preview, upload the project folder to a static host such as Netlify Drop. Keep the HTML and MP3 assets together.
- If opened directly as a local file and 3D fails to initialize, try hosting the folder instead.

## Mobile controls
- Left joystick: move, jump, crouch, and sidestep using the joystick directions.
- Square: light attack; Cross: heavy attack; Triangle: special; Circle: ultimate; R1: guard; R2: dash.
- Portrait layout received a small spacing adjustment in the 2026-10-14 patch. Verify on the target phone after publishing.

## Files
- `shadow-clash-forest-3d.html`: main game.
- `shadow-clash-song.mp3`, `321fightSoundeffect.mp3`: audio assets.
- `CHANGELOG.md`: changes in this patch.
- `TEST-REPORT.md`: executed checks and limitations.

This package does not claim verified WebGL rendering or real-device Android performance.
